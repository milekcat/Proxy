# ProxyVPN — Android IPv4 proxy to VPN (MVP)

Простой Android-клиент, который использует системный `VpnService` для передачи IPv4 TCP-трафика через пользовательский SOCKS5 / HTTP / HTTPS CONNECT-прокси.

> **Состояние:** исходный проект MVP, **не production-ready**. В рамках подготовки выполнены локальные тесты кодека IPv4, SOCKS5 с логином и паролем, UDP ASSOCIATE и HTTP CONNECT. На реальном Android-устройстве приложение и сборка APK здесь **не проверялись**. Нативного Android SDK в среде подготовки нет, поэтому исходный архив **не содержит собранного APK**.

## Функции

- **Весь телефон:** перехват IPv4 TCP и DNS для всех приложений через Android `VpnService`.
- **Только выбранные приложения:** в интерфейсе включите соответствующий переключатель, отметьте приложения с иконкой запуска и подключитесь. Используется `VpnService.Builder.addAllowedApplication(...)`. Остальные приложения используют обычное соединение вне VPN.
- **SOCKS5** с авторизацией по логину и паролю (`RFC 1928`, `RFC 1929`). TCP CONNECT + UDP ASSOCIATE, если разрешён прокси-сервером.
- **HTTP CONNECT** с Basic-авторизацией. TCP-трафик.
- **HTTPS CONNECT**: HTTP CONNECT внутри TLS-соединения к самому прокси; сертификат должен быть доверенным и подходить к введённому IP-адресу. TCP-трафик.
- **DNS**: запросы UDP/53 внутри VPN обрабатываются через DNS-over-HTTPS к `cloudflare-dns.com` или `dns.google` по соединению, установленному **через прокси**.
- Учётные данные хранятся через Android Keystore AES-GCM. Нет регистрации, SDK аналитики или собственных серверов приложения.
- Фоновая служба с постоянным уведомлением, проверкой доступности прокси на старте (через прокси к двум DoH-адресам) и кнопкой отключения.

## Как скачать APK с GitHub Actions (без Android Studio)

1. Создайте **частный** (рекомендуется) GitHub-репозиторий.
2. Распакуйте этот проект и загрузите **содержимое** папки `ProxyVPN-Android/` в корень репозитория (включая `.github/workflows/build-apk.yml`).
3. Откройте вкладку **Actions → Build debug APK → Run workflow**. При обычной загрузке в ветку `main` сборка также запустится автоматически.
4. После успешной сборки откройте run → **Artifacts** → **ProxyVPN-debug-apk**.
5. Из скачанного архива извлеките `app-debug.apk` и установите его на телефон. Android предложит разрешить установку из выбранного источника.

GitHub Actions может потребовать включить Actions в настройках репозитория. Сборка скачает официальные зависимости Android Gradle Plugin/Android SDK во время выполнения. Проект содержит исходники и конфигурацию workflow, но **не APK** и **не бинарный Gradle wrapper**.

## Сборка на ПК

- JDK 17; Gradle 8.9; Android SDK Platform 35 и Build Tools 35.0.0.
- В Android Studio откройте папку проекта, настройте установленный Gradle 8.9, выполните `:app:assembleDebug`.
- Либо из терминала с настроенным Android SDK и установленным Gradle 8.9:

```bash
gradle :app:assembleDebug
```

- Результат: `app/build/outputs/apk/debug/app-debug.apk`.

### Локальные проверки (только JDK 17, Android SDK не требуется)

```bash
bash tests/offline/run.sh
```

Тесты собирают Java-часть пакетного движка с **тестовыми** заглушками Android, эмулируют локальные SOCKS5/HTTP-прокси и проверяют переговоры и передачу данных. Они не заменяют Android-сборку или испытания VPN на устройстве.

## Настройка на телефоне

1. Запустите ProxyVPN.
2. Укажите тип: `SOCKS5`, `HTTP CONNECT` или `HTTPS CONNECT`.
3. Вставьте **IPv4-адрес сервера**, порт, логин и пароль.
4. Для всего телефона оставьте флажок **«VPN только для выбранных приложений»** выключенным.
5. Для выборочного режима включите флажок, нажмите **«Выбрать приложения»** и отметьте нужные приложения. Не оставляйте список пустым.
6. Нажмите **«Подключить»**, подтвердите стандартный системный запрос Android VPN. Для отключения нажмите **«Отключить»**.
7. Убедитесь, что интернет действительно работает через прокси: проверьте внешний IP в браузере **внутри выбранного приложения**; проверьте также, что невыбранные приложения идут напрямую.

При смене списка приложений нужно нажать «Подключить» повторно. Android может запретить запуск VPN одновременно с другим VPN-клиентом.

## Ограничения и безопасность

- Реализован **IPv4 TCP userspace proxy stack**, не полноценная промышленная TCP/IP-реализация. На нестабильной сети, с потоковым видео, большими загрузками и некоторыми приложениями возможны сбои. Профиль нельзя считать проверенным без тестов на физическом устройстве.
- **IPv6 блокируется** VPN-маршрутом, а не туннелируется. ICMP (ping) и IP-фрагменты блокируются. Это сделано для недопущения прямого обхода прокси, но часть приложений может не работать.
- **UDP через HTTP/HTTPS CONNECT не поддерживается** и отбрасывается, кроме DNS-запросов через DoH. SOCKS5 UDP будет работать только если конкретный прокси поддерживает команду UDP ASSOCIATE и его UDP-реле достижимо с телефона.
- UDP DNS перехватывается на 53 порту и идёт через DoH, однако некоторые приложения используют **собственный DoH/DoT** (TCP/HTTPS) или QUIC. Их поведение зависит от транспорта и настроек приложения. DoH-провайдер видит DNS-запросы.
- SOCKS5 и HTTP CONNECT **сами по себе не шифруют** канал между телефоном и прокси. Их логины/пароли могут быть прочитаны на этом участке сети. В режиме HTTPS CONNECT TLS до прокси шифрует этот участок, но у IPv4-прокси должен быть правильно оформленный сертификат.
- Не включайте в код реальные прокси-логины/пароли. Введите их только после установки приложения.
- Перечень приложений в выборочном режиме показывает программы с launcher-активностью, не все фоновые системные службы. **Не выбранные** приложения не защищены VPN по определению.
- Если нужен системный **kill switch**, используйте встроенную настройку Android «Всегда включённый VPN» и «Блокировать соединения без VPN» **в режиме всего устройства**; в выборочном режиме это может повлиять на работу остальных приложений.
- Состояние «VPN включён» до завершения проверки прокси означает только установленный системный туннель. При недоступности прокси туннель остаётся активным и **блокирует** передаваемый через него трафик вместо перехода на прямое соединение.
- App не содержит отслеживания подключений, журналов трафика, подписок или автообновления. Нет автоматического восстановления после перезагрузки.
- **Не используйте это MVP для задач, где критична надёжность или строгая защита от утечек.** Для такой цели потребуется зрелый туннельный движок, полноценное тестирование TCP/UDP/IPv6 и security review.

## Структура

```text
app/src/main/java/com/proxyvpn/app/
  MainActivity.java     — настройки и выбор приложений
  ProxyVpnService.java  — VpnService, Android маршрутизация, уведомление
  ProxyConfig.java      — конфиг и шифрованное сохранение
  ProxyTransport.java   — SOCKS5 / HTTP CONNECT / HTTPS CONNECT
  PacketEngine.java     — TCP/UDP userspace gateway
  PacketCodec.java      — IPv4/TCP/UDP кодек и проверки сумм
  DnsOverHttps.java     — DNS через TLS к DoH через прокси
.github/workflows/build-apk.yml — облачная debug APK сборка

tests/offline/ — локальные тесты, не попадают в APK
```
